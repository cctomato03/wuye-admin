# 小区物业管理系统 · 操作手册

本手册面向两类使用者：**平台管理员**（平台超级管理员，管理所有物业公司与小区）和
**物业公司管理员/员工**（在所属公司范围内管理小区业务）。

> 通用约定：所有业务数据都归属某个小区；进入业务页面前先在顶部选择「当前小区」，选择结果会记住，切换小区后各页面自动沿用。

---

## 一、登录与工作台

1. 打开系统地址，输入账号、密码与验证码（滑动手柄时按提示拖动）。
2. 首次登录后可在「个人中心」修改密码、维护头像与联系方式。
3. 工作台展示：平台/物业概览、待办与消息（点击可跳转业务单据）。

---

## 二、平台管理员

### 2.1 创建物业公司（= 租户）

入口：**系统设置 → 物业公司与小区 → 物业公司页签**

1. 点「新增物业公司」，填公司编码（小写字母开头，唯一）、名称、统一社会信用代码、联系人/电话、合作状态。
2. 可留空管理员账号/密码：系统自动生成 `admin_公司编码` 与随机密码，**创建成功后弹窗只显示一次**，请立即记录。
3. 系统会自动完成：建公司根部门 → 建内置角色「物业公司管理员」→ 建管理员账号。
4. 「物业公司管理员」拥有除 **系统监控 / 系统设置 / 物业公司与小区 / 菜单管理** 之外的全部菜单，
   可在本公司内继续创建角色、用户、部门、岗位、员工。

### 2.2 创建小区

入口：**系统设置 → 物业公司与小区 → 小区页签**

1. 选择所属物业公司（下拉可搜所有公司），填小区编码、名称、类型、详细地址。
2. 「所属行政区」逐级选择省 → 市 → 区县 → 街道 → 社区，选择后自动带出完整路径与编码。
3. 可维护占地面积、交付日期、物业负责人、客服电话；保存后可在列表启用/停用。

### 2.3 权限与组织（平台侧）

> 组织与权限的数据**按物业公司隔离**。平台默认租户的用户进入「用户/角色/部门/岗位/员工」页面时，
> 顶部会有**「物业公司」下拉**（与小区页面的小区切换一致），选择哪家公司就管理哪家的组织数据；
> 物业公司自己的用户看不到这个下拉，只能管理本公司。

- **默认内置角色只有两个**：超级管理员（全权限）、物业管理员（除系统设置/系统监控/菜单管理之外的全部权限）；
  新建物业公司时自动创建该公司的「物业管理员」角色与管理员账号。
- **菜单管理**属于平台级权限，物业公司管理员不可见、不可改，避免越权修改平台菜单结构。

- **角色管理**：新增角色时选择「可管理小区」（当前所选物业公司的全部 / 指定若干）。
  给角色授权时，**可授出的菜单**与**可分配的小区**都不会超过你自己的权限。
- **用户/员工**：新增用户需选择本公司角色；员工可同时开通登录账号并授权小区。
- **字典管理**：维护「小区层级类型」（`space_node_type`：区域/楼栋/单元/楼层）等业务字典。

### 2.4 监控与运维

- **在线用户**：查看当前在线会话，可强制下线。
- **登录/操作日志**：按时间、账号、模块检索；操作日志记录字段级变更。
- **服务器信息**：CPU/内存/磁盘与运行时长。

## 三、物业公司管理员

### 3.1 小区基础信息管理

入口：**小区管理 → 基础信息管理**。页面结构：顶部小区卡片 + 左侧层级树 + 右侧信息卡片。

**新建层级**
1. 点树上方「新建」，选择**上级层级**（小区为唯一顶级）、填**层级名称**、选**层级类型**（区域/楼栋/单元/楼层，来自系统字典）。
2. "上级层级"是多级树形下拉（顶层为"小区（顶级）"）；若先在左侧树里选中了某个层级再点「新建」，
   表单会自动把该层级作为上级；没有选择时默认小区（顶级）。
3. 不需要填编码；**同一上级下名称不能重复**。
3. 层级地址自动生成：`上级地址 + 本层名称`（小区下一级 = 小区地址 + 名称）；改名或换上级会自动刷新所有下级地址。

> 没有区域/单元的小区也能用：例如住宅 `1栋 → 1单元 → 1层`，别墅直接 `别墅区 → 1号别墅`，商业楼 `商业楼 → 1层`。

**层级信息卡片**（点击左侧层级）
- 显示：`{类型}名称`（如楼栋名称）、`{类型}范围`（下级名称标签）、房屋总数（含所有下级）、住户人数、
  关联设备（本层级及以下）、`{类型}地址`、上级层级与路径。
- 下方列出该层级下的房屋，点「查看」直接切到房屋卡片。
- 卡片右上角可直接：新增下级 / 编辑 / 新增房屋 / 删除（有子层级或房屋时不允许删除）。

**房屋卡片**（点击左侧房屋）
- 显示房屋编码、房号、用途、建筑/套内/公摊面积、类型、状态、地址；
- **住户信息**：姓名、身份（业主/家属/租户）、与业主关系、电话、入住日期、有效期、是否主联系人；
- **车辆信息**：车牌号、车型、车位号。

**新增房屋**
- 「所属层级」可选 **小区（直接挂载）** 或任意层级（不做限制）；
- **房屋编码 + 建筑面积为必填**；其余（套内/公摊、户型朝向、装修、产权性质、临街与门面宽、层高、交付日期、附属设施）按需填写。

**导入 Excel（房屋地址解析）**
- 右上角只保留「导入 Excel」和「下载模板」两个按钮。
- 模板只有三列：**房屋编码、房屋地址、房屋面积**（面积可留空，留空按 0 处理）。
- 房屋地址格式 = **小区地址 + 小区名称 + 层级结构 + 房屋名称**，例如：
  `湖北省武汉市江岸区黄浦大街25号黄浦雅苑1栋4单元1楼1号`
  （`湖北省武汉市江岸区黄浦大街25号` 是小区的行政区划+地址，`黄浦雅苑` 是小区名称）。
- 系统按 区 / 栋 / 单元 / 层(楼) / 号 自动切分：`1栋`(楼栋) `4单元`(单元) `1楼`(楼层) `1号`(房屋名称)；
  缺失的层级会自动补齐（如只有 `1栋1号`，则房屋直接挂楼栋；只有 `1号`，则直接挂小区）。
- 校验规则：房屋编码、房屋地址不能为空；地址必须以「小区地址+小区名称」开头；编码不能重复。
  任一行不合格会在导入结果中**逐行列出**错误原因（如"第 2 行：房屋地址与小区不匹配，应以…开头"）。

### 3.2 住户与人员

- **住户登记**：输入证件号自动回显历史资料（仅本公司范围）→ 选择房屋、身份、有效期（租户必须填到期日）→ 保存。
- **房屋关系**：可续期、解绑、恢复；住户可上传人脸用于门禁。
- **访客登记**：登记来访人、受访房屋（按房屋 ID 关联）、事由与有效期；可标记进入/离开/取消。
- **其他人员**：保姆、装修工、外卖等临时人员，按分类与有效期管理。

### 3.3 单位与车辆

- **单位管理**：登记商铺/办公单位，必须绑定具体房屋（保存房屋 ID）。
- **车辆管理**：车辆档案与车位，同样按房屋 ID 关联；支持业主/员工/单位车辆。

### 3.4 收费管理

1. **收费项目**：按小区建项目（物业费/水/电/停车/其他），选择计费方式（按面积·月、按面积·天、按用量、固定金额、按套）。
2. **收费标准**：为项目配置生效区间与单价。
3. **生成账单**：按项目 + 账期批量生成；抄表类项目先录入「抄表」读数再生成。
4. **缴费**：现金/微信/支付宝/余额；余额不足会自动提示；已缴账单可查看明细。
5. **缴费记录**：按小区、账期、房屋、状态检索；可作废未缴账单。

### 3.5 设备与门禁

- **设备信息**：维护门禁机/道闸/摄像头等，绑定范围可选「小区级」或「指定层级」（层级下所有房屋共享该设备）。
- **门禁授权**：按人员（住户/员工/访客/其他）下发权限，系统按「房屋 → 层级路径 → 小区」自动收集可用设备；
  可查看卡片、重试下发、撤销授权。

### 3.6 组织与权限（公司内）

> 页面顶部**没有**物业公司切换：物业公司管理员只能管理本公司的用户/角色/部门/岗位/员工；
> 所有新增数据自动落在本公司租户下。把 tenantId 改成别家公司会直接返回 403。


- **员工管理**：新增员工可同时创建账号、分配角色、授权小区；未选角色时不允许开账号（避免登录后无数据）。
- **角色管理**：子角色的菜单与小区范围不能超过你自己的权限；授权弹窗内可同时设置「可管理小区」。
- **用户/部门/岗位**：与平台同一套组织模型，数据落在本公司租户内。

## 四、常见问题

| 现象 | 处理 |
| --- | --- |
| 页面提示「当前物业公司暂无管理小区」 | 由平台管理员在「物业公司与小区」为本公司创建小区；公司管理员无权新增小区 |
| 新增层级提示「同一上级下已存在同名层级」 | 同一上级下名称必须唯一，改名或换上级即可 |
| 新增房屋提示「请填写建筑面积」 | 房屋编码与建筑面积为必填 |
| 导入 Excel 报「第 N 行：…」 | 按行提示修正（多为层级路径或房屋编码为空、编码重复） |
| 员工登录后看不到数据 | 检查其角色是否绑定了可管理小区，或员工是否被单独授权小区 |
| 账单无法扣余额 | 先在「缴费记录 → 账户充值」为房屋账户充值，或改用其他支付方式 |
| 登录时验证码/滑块不显示 | 平台可在字典/参数中开关 `sys.login.captcha`、`sys.login.slider` |
